
# Health Monitoring Software for Astronauts
 
This is our official solution to the NASA Space Apps Challenge "Create Health Monitoring Software for Astronauts on Space Missions."
 
On long missions, astronauts face radiation, isolation, altered gravity and a closed environment, which can lead to immune changes, bone loss, cardiovascular problems and mental strain. Since they're often the first ones to notice these changes in themselves, we built software that collects key health indicators in one place and shows them in a clear way. It helps astronauts see where they stand, spot worrying trends early, and decide what to do next.
